# 轻译 (QingYi) — 实时屏幕与声音字幕翻译

极简浅色设计的双端（**Windows 独立 EXE** + **Android 全局悬浮窗 APK**）实时屏幕区域、快捷键截图与电脑/麦克风声音字幕翻译软件。

## 直接下载安装（开箱即用，支持国内免代理直连）

- **Windows 电脑端（免安装便携版）**：**[点击下载 QingYi-Windows-x64.zip](https://github.com/huilygyc/qingyi-translator/releases/latest/download/QingYi-Windows-x64.zip)**
  - 解压后直接双击 `轻译/轻译.exe` 即可弹出浅色控制面板，无需安装 Python。
  - **Windows 安全提示说明**：因个人开源软件未购买商业代码签名证书，首次双击时若 Windows Defender SmartScreen 弹出蓝框提醒，点击「更多信息 -> 仍要运行」即可。
- **Android 手机端（浅色全局悬浮窗版）**：**[点击下载 QingYi-Android.apk](https://github.com/huilygyc/qingyi-translator/releases/latest/download/QingYi-Android.apk)**
- **全部历史版本**：**[前往 Releases 页面查看](https://github.com/huilygyc/qingyi-translator/releases)**

## 核心特性（v1.3.2）

1. **多线路 400 ms 阶梯抢跑翻译（国内免代理可用）**
   - 内置 **Google Keep-Alive 长连接** 与 **国内免代理直连线路（有道直连 + MyMemory）** 并发竞速，主通道超 400 ms 自动拉起备用通道抢答，常规延迟压至 **~70 ms**；亦可在「偏好设置」切换为「国内直连免代理」或接入 **DeepSeek / 任意 OpenAI 兼容大模型**。
2. **低优先级后台抓屏 + 全屏防卡保护 + 一键底部字幕区**
   - 桌面端内置优化后的 RapidOCR PP-OCRv6（~50 ms），抓屏与像素对比全面移至低优先级后台线程并复用缓冲，即使直接框选全屏也会自动预降采样、平滑限流并保留 CPU 冷却空隙；4 个微型独立角标彻底消除全屏透明层显卡负担，主面板支持一键锁定“底部字幕区”。
3. **影院级悬浮字幕与轻量弹幕流（双端同步）**
   - **丝滑过渡动画**：新台词 150 ms 轻柔淡入上浮，无台词 300 ms 自动渐隐，告别硬切闪烁。
   - **底板贴合文字 + 底部锚定防跳动**：自适应 Fit-Content 胶囊底板不挡无关画面，单行/双行切换稳稳贴合底部水平线。
   - **双句留存 & 轻量弹幕流模式**：可选保留上一句缩小淡化在上方防语速太快漏看，或一键切换为 3 层上浮气泡弹幕流。
   - **柔光多层阴影 & 矢量真预览**：设置页实时渲染真实描边渐变效果；支持**滚轮缩放字号**、**右键一键复制**、**冻住当前句**，以及一键**“贴合原字幕上方 / 遮盖原硬字幕”**（配合防重复识别，可直接盖住原外语字幕观看）。
4. **低延迟流式语音听译（电脑原声 + 麦克风，支持 SenseVoiceSmall）**
   - 支持 Windows WASAPI 内录电脑正在播放的视频声音或麦克风说话声；采用**自适应动态底噪 VAD**（抗 BGM 干扰，0.24 秒快切）、**0.9 秒实时流式边说边译**、**启动预热 + 零积压并发翻译管线**，大幅压低语音出字延迟；除内置 Faster-Whisper 外，还支持一键切换阿里开源 **SenseVoiceSmall（ONNX）**。
5. **双端词表双向同步与便捷交互**
   - 桌面端左侧「快捷键」页支持点击按键框直接按键盘录制修改（默认：截图 `Alt+Q`、框选 `Alt+R`、区域翻译 `Alt+S`、声音翻译 `Alt+A`、穿透锁定 `Alt+L`）；点关闭默认最小化到托盘防误退，支持导出 `.srt` 与软件内一键检查新版本。
   - Android 手机端统一极简浅色界面，连接电脑局域网地址后支持**一键双向同步专有名词词表**。
